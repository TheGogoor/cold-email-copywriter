# Cold Email Copywriter

A Claude Code skill for writing cold emails, follow-up sequences and other B2B outreach copy.

Give it the sender, the target and the goal, and it writes 10 email variants, each from a different angle. It includes 13 psychological principles, about 20 email templates, follow-up and CTA frameworks, subject line rules, banned phrases and spam words, and a pre-send checklist.

## Install

Copy `SKILL.md` to `~/.claude/commands/cold-email-copywriter.md`, or to `~/.claude/skills/cold-email-copywriter/SKILL.md`. Then run `/cold-email-copywriter` in Claude Code, or just ask for cold email copy.
